How this works

  1. In Discord, run /avwx config edit. The bot replies with a link that opens this page with your server's current settings and channel list.
  2. Change what you like below.
  3. Press Download config.json, then run /avwx config import in Discord and attach the file. The bot shows what will change and waits for you to press Apply.

Everything happens in your browser. Your server's details travel in the part of the link after #, which browsers never send to the web server.
